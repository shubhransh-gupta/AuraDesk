Under The Hood

How AetherWall Conquers the macOS Lock Screen

macOS Sonoma, Sequoia, and Tahoe block normal third-party windows from rendering above the secure login session. AetherWall solves this natively in three automated steps.

01

Zero-Reencode .MOV Remux

Drop any .mp4 or .mov file. AetherWall uses AVAssetExportPresetPassthrough to wrap the 4K stream into an Apple-compliant QuickTime container in milliseconds without losing quality.

02

Binary Plist Store Injection

Automatically serializes nested binary property lists inside com.apple.wallpaper/Store/Index.plist so macOS points your Lock Screen (Idle) to the high-framerate Aerial video pipeline.

03

Safe Backup & idleassetsd Swap

Backs up Apple's original 4KSDR240FPS asset first, injects your custom 4K video with one native macOS admin prompt, and reloads WallpaperAgent. Restore original anytime in 1 click.
